# 🍽️ Trek Meal Pro - Планирование питания в походе (v2.1)

Профессиональное веб-приложение для детального планирования питания в походах и путешествиях. Помогает рассчитать необходимое количество продуктов, их вес и пищевую ценность с учетом всех участников и дней.

## ✨ Ключевые возможности

- **Управление походами**: Создавайте походы с указанием дат, участников, сложности и питания.
- **База продуктов**: Ведите собственную базу продуктов с указанием пищевой ценности, веса порций, категорий и других атрибутов.
- **Библиотека блюд**: Создавайте и сохраняйте шаблоны блюд (наборы продуктов) для быстрого добавления в раскладку.
- **Управление участниками**: Создавайте профили участников с их особенностями.
- **Детальное планирование питания**: Распределяйте продукты и готовые блюда по дням и приёмам пищи.
- **Автоматические расчеты**: Мгновенный подсчет общего веса, калорийности, БЖУ и среднего веса на человека в день, корректно учитывающий уникальную раскладку каждого дня.
- **Целостность данных**: Система не позволит удалить продукт или блюдо, если они используются в раскладках, предотвращая ошибки.
- **Сохранение данных**: Вся информация сохраняется локально в вашем браузере, используя `localStorage`.
- **Современный UI/UX**: Чистый, адаптивный дизайн, построенный на современных компонентах, включая удобный выбор дат и списки с поиском.
- **Навигация**: Удобная навигация с использованием URL, позволяющая сохранять ссылки на конкретные походы.

## 🚀 Запуск приложения

### Предварительные требования

- Node.js v14 или выше
- npm или yarn

### Установка и запуск

1.  **Клонируйте репозиторий и установите зависимости:**

    ```bash
    git clone <your-repo-url>
    cd trek-meal-pro
    npm install
    ```

2.  **Запустите приложение в режиме разработки:**

    ```bash
    npm start
    ```

3.  Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🛠️ Стек технологий

- **React 19**: Основной фреймворк с использованием Hooks.
- **TypeScript**: Для строгой типизации и повышения надежности кода.
- **React Router 6**: Для навигации на стороне клиента.
- **Zustand**: Для централизованного, простого и производительного управления состоянием.
- **Tailwind CSS**: Для быстрой и консистентной стилизации компонентов.
- **React Select**: Для удобных выпадающих списков с поиском.
- **React Datepicker**: Для интуитивного выбора дат.
- **ESLint + Prettier + Husky**: Для обеспечения высокого качества и единого стиля кода.

## 🎯 Ключевые архитектурные решения

- **Атомарное управление состоянием (Zustand):** Вместо единого громоздкого хранилища, состояние приложения разделено на независимые, логические модули (`useTripStore`, `useProductStore` и т.д.). Это делает управление данными предсказуемым, тестируемым и легким для понимания.
- **Единый источник правды для расчетов (DRY):** Вся логика для расчета веса, калорий и других метрик вынесена в утилитарную функцию `calculateTripSummary` в `utils.js`. Это гарантирует консистентность данных во всем приложении и соответствует принципу "Don't Repeat Yourself".
- **Строгая типизация (TypeScript):** Весь проект написан на TypeScript с использованием централизованного файла `types.ts`, что минимизирует ошибки во время выполнения, упрощает рефакторинг и улучшает опыт разработки.
- **Автоматический контроль качества кода:** Благодаря связке ESLint, Prettier, `lint-staged` и Husky, весь код автоматически проверяется и форматируется перед каждым коммитом, обеспечивая высокий стандарт качества.
