# 🍽️ Trek Meal Pro - Планирование питания в походе (v2.0)

Профессиональное веб-приложение для детального планирования питания в походах и путешествиях. Помогает рассчитать необходимое количество продуктов, их вес и пищевую ценность с учетом всех участников и дней.

## ✨ Ключевые возможности

-   **Управление походами**: Создавайте походы с указанием дат, участников, сложности и питания.
-   **База продуктов**: Ведите собственную базу продуктов с указанием пищевой ценности, веса порций и других атрибутов.
-   **Управление участниками**: Создавайте профили участников с их особенностями.
-   **Детальное планирование питания**: Распределяйте продукты по дням и приемам пищи для каждого похода.
-   **Автоматические расчеты**: Мгновенный подсчет общего веса, калорийности, БЖУ и среднего веса на человека в день.
-   **Умные предупреждения**: Система оповестит, если вес или калорийность выходят за рамки разумного.
-   **Сохранение данных**: Вся информация сохраняется локально в вашем браузере.
-   **Современный UI/UX**: Чистый, адаптивный дизайн, построенный на современных компонентах.
-   **Навигация**: Удобная навигация с использованием URL, позволяющая сохранять ссылки на конкретные походы.

## 🚀 Запуск приложения

### Предварительные требования

-   Node.js v14 или выше
-   npm или yarn

### Установка и запуск

1.  **Клонируйте репозиторий и установите зависимости:**
    ```bash
    git clone <your-repo-url>
    cd trek-meal-pro
    npm install
    ```

2.  **Запустите приложение в режиме разработки:**
    ```bash
    npm start
    ```

3.  Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🛠️ Стек технологий

-   **React 18**: Основной фреймворк с использованием Hooks.
-   **React Router 6**: Для навигации на стороне клиента.
-   **React Context**: Для централизованного управления состоянием приложения.
-   **Styled Components v6**: Для стилизации компонентов.
-   **React Select**: Для удобных выпадающих списков с поиском.

## 🎯 Ключевые архитектурные решения

-   **Централизованное состояние (React Context):** Вместо передачи пропсов через множество уровней (prop drilling), все основное состояние (походы, продукты, участники) и логика для работы с ним находятся в `AppContext`. Это делает компоненты чище и упрощает управление данными.
-   **Единый источник правды для расчетов (DRY):** Вся логика для расчета веса, калорий и других метрик вынесена в утилитарную функцию `calculateTripSummary` в `utils.js`. Это гарантирует консистентность данных во всем приложении и соответствует принципу "Don't Repeat Yourself".
-   **Роутинг на стороне клиента:** Использование `react-router-dom` обеспечивает стандартный для SPA-приложений пользовательский опыт с уникальными URL для каждой страницы, что позволяет использовать историю браузера и делиться ссылками.
