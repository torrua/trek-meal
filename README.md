# 🍽️ Trek Meal - Планирование питания в походе

Веб-приложение для планирования питания во время походов и путешествий. Помогает рассчитать необходимое количество продуктов по приемам пищи и дням.

## ✨ Возможности

- **Планирование похода**: Укажите количество дней, участников и приемов пищи
- **Управление продуктами**: Добавляйте продукты с указанием веса и калорийности
- **Планирование питания**: Распределяйте продукты по дням и приемам пищи
- **Автоматические расчеты**: Вес продуктов автоматически пересчитывается с учетом количества участников и дней
- **Итоговая сводка**: Детальная статистика по весу, калориям и распределению продуктов
- **Адаптивный дизайн**: Работает на всех устройствах

## 🚀 Запуск приложения

### Предварительные требования

- Node.js версии 14 или выше
- npm или yarn

### Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите приложение в режиме разработки:
```bash
npm start
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

### Сборка для продакшена

```bash
npm run build
```

## 📱 Как использовать

1. **Настройте параметры похода**:
   - Укажите количество дней
   - Введите число участников
   - Выберите количество приемов пищи в день

2. **Добавьте продукты**:
   - Название продукта
   - Вес в граммах
   - Калорийность (опционально)

3. **Спланируйте питание**:
   - Выбирайте продукты для каждого приема пищи
   - Приложение автоматически рассчитает общий вес

4. **Просмотрите сводку**:
   - Общий вес продуктов
   - Распределение по дням
   - Калорийность
   - Детализация по продуктам

## 🎯 Особенности

- **Автоматические расчеты**: Вес продуктов пересчитывается с учетом всех параметров
- **Умные предупреждения**: Приложение предупреждает о возможных проблемах с питанием
- **Гибкая настройка**: От 3 до 5 приемов пищи в день
- **Детальная статистика**: Полная информация о планируемом питании

## 🔧 Настройка

Приложение можно легко настроить под свои нужды:

- Изменить максимальное количество дней (по умолчанию 30)
- Настроить максимальное количество участников (по умолчанию 20)
- Добавить новые типы приемов пищи
- Изменить цветовую схему в styled-components
