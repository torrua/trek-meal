# Проблема: Разные селекты для похожих задач

## 🔴 Выявленная проблема

В приложении используются **два разных селекта** для похожих задач:

### **ThemedSelect** (на базе react-select)
Используется в:
- ✅ `TripForm.tsx` - выбор сложности похода
- ✅ `MealForm.tsx` - выбор продуктов/блюд
- ✅ `DishForm.tsx` - выбор продуктов

### **DropdownSelect** (кастомный компонент)
Используется в:
- ❌ `ProductForm.tsx` - выбор категории продукта

## 📊 Сравнение

| Параметр | ThemedSelect | DropdownSelect |
|----------|-------------|----------------|
| Внешний вид | Стиль react-select | Кастомный Notion-style |
| Высота | 40px (исправлено) | 40px (исправлено) |
| Функциональность | Мощный, много опций | Простой, базовый |
| Кастомизация | Гибкая через стили | Фиксированный стиль |

## 🎯 Рекомендация решения

**Оставить ThemedSelect как единый стандарт** по следующим причинам:

1. **Функциональность**: Больше возможностей (поиск, мультиселект, кастомные опции)
2. **Консистентность**: Уже используется в большинстве форм
3. **Поддержка**: react-select - проверенная библиотека
4. **Будущие нужды**: Легче расширять функциональность

## 📋 План унификации

### Этап 1: Заменить DropdownSelect на ThemedSelect в ProductForm
- ✅ Унифицировать интерфейс категории продукта
- ✅ Использовать тот же стиль что и в других формах

### Этап 2: Обновить стили ThemedSelect
- ✅ Добавить Notion-style дизайн
- ✅ Улучшить визуальную консистентность

### Этап 3: Удалить DropdownSelect (если не используется в других местах)
- Проверить все использования DropdownSelect
- Если не используется - удалить компонент
