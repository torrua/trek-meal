# Дизайн-система (актуальное кратко)

- Базовые контейнеры: `.page-shell` для ширины/отступов; `.section-card` для блоков (фильтры, формы), `.action-bar` для групп кнопок, `.selection-pill` для счетчиков выбора.
- Заголовки страниц: `PageHeader` (`src/ui/PageHeader.tsx`) — принимает `title`, `actions`, `selectionInfo`. Использовать вместо ручной сборки шапок.
- Списки: `EntityListItem`/`EntityCard` — единая типографика (`w-4 h-4` иконки, `gap-4` между метриками, hover/selected ring). Все списки должны идти через эти компоненты.
- Формы и фильтры: `FormField`, `Input`, `DropdownSelect` — общие отступы и подписи. Для фильтров использовать `FiltersPanel` либо карточку с `.section-card`.
- Действия: первичные — `variant=\"primary\"`, вторичные — `variant=\"secondary\"`, опасные — `variant=\"danger\"`, иконки 16px. Минимизируем модалки, используем inline/страничные действия.
- Навигация/табы: `TabNavigation` с иконками 16px, счетчики в чипах.
- Состояния: для многовыбора `selectionInfo` + `action-bar`, без модалки там, где можно inline.

Эталонные реализации: `/meals`, `/dishes` (структура страницы, список/деталь, шапка, действия).
